# Design: Fix 6 Defects in c028bcb9 Structured-Flags Commit

## Summary

Resolve the 3 critical (I1-I3) and 3 important (Q1-Q3) findings from the c028bcb9 review without expanding scope. The fix combines three layered changes: (a) gate the image-promotion block in `provider.ts` on both `!isBudgetExceeded` and `!pinnedTier` so the budget-forced and pinned-tier signals cannot be silently overridden; (b) drop the dead `level` parameter from `getUnsupportedTiers` and let callers keep their `'off'` guards; (c) expand `isValidRoutingDecision` into a field-by-field sanitizer that strips invalid optional fields instead of rejecting the whole persisted state. All changes are minimal-diff against `routing.ts`, `provider.ts`, `config.ts`, `state.ts`, `index.ts`, with parallel updates to their test files.

## Requirements

From the review (`2026-07-18_19-08-10_commit-structured-flags.md`):

- **I1**: Budget downgrade (high→medium, medium→low) is silently undefeated by image-promotion; `isBudgetForced` carried onto a decision whose tier was promoted past the cap.
- **I2**: Google thought-signature guard's `!pinnedTier` skip + image-promotion's `tiersToTry` ignoring `pinnedTier` lets the pinned-low tier's image promotion override the pin.
- **I3**: `getUnsupportedTiers` accepts `level: ThinkingLevel` but its body never reads it; both production callers pre-filter `'off'`, so the removed `'off'` short-circuit is unreachable in production.
- **Q1**: Notify chain (`index.ts:99-107`) and `getDecisionFlags` (`ui.ts:19-26`) have different orderings and the chain silently drops `isVetoed`.
- **Q2**: `isValidRoutingDecision` (`state.ts:29-36`) validates only `profile`/`tier`/`timestamp`; all-or-nothing reject at `state.ts:66` discards `enabled`/`selectedProfile`/`accumulatedCost` if any field of `lastDecision` is invalid.
- **Q3**: Budget downgrade `else-if` chain caps at one step; `tier === 'low' && isBudgetExceeded` is silent (no `isBudgetForced` set, no notification).

## Current State Analysis

### Key Discoveries

- `isBudgetExceeded` is captured at `provider.ts:300` as a `const` snapshot before `decideRouting` runs; it's also stamped on the decision via `routing.ts:434-444` as `isBudgetForced`. Both signals exist; the image-promotion block at `provider.ts:386-405` reads neither.
- `pinnedTier` is captured at `provider.ts:298` and used in the Google continuation guard at `provider.ts:344`; the image-promotion block does not consult it.
- `containsAnyWord` regex cache at `routing.ts:76` is module-level and unbounded — a concern (Q4) but deferred per scope.
- `buildDelegationTierChain` (`routing.ts:110-122`) and `resolveAvailableTier` (`routing.ts:122-155`) iterate tiers in opposite orders (down-then-up vs. up-then-down) — Q6 deferred.
- `isRouterPersistedState` (`state.ts:30-77`) follows a validate-if-present pattern (`accumulatedCost` at `:48-56` is the template) but its `lastDecision` branch at `:66` is all-or-nothing, breaking the pattern.
- `recordDebugDecision` notify chain (`index.ts:99-107`) and `getDecisionFlags` (`ui.ts:19-26`) are the only two consumers of `lastDecision`'s provenance flags; no other readers.
- `getUnsupportedTiers` body at `config.ts:692-704` never references the `level` parameter; the removed short-circuit is documented in code comments as "Decision 9" but the callers (`index.ts:518`, `commands.ts:370`) still pre-filter `'off'`.
- `provider.ts:417-425` carry-forward uses field-by-field assignment (post-`buildRoutingDecision` mutation), not spread. This pattern is acceptable for re-stamping provenance but should not be the model for new decision construction.
- The Google continuation guard's `!pinnedTier` skip (`provider.ts:344`) is correct _if_ the image-promotion block no longer mutates tier when pinned — the fix is to gate the promotion block on `pinnedTier`, not to change the guard.

### Pattern References

- `state.ts:9-15` — `isValidPinByProfile` per-field validation pattern.
- `state.ts:48-56` — `accumulatedCost` validate-if-present + reject-whole pattern.
- `config.ts:42-46` — `isRouterTier` equality-chain type guard style.
- `config.ts:37-40` — `isObjectRecord` narrowing to `Record<string, unknown>`.

## Scope

Required fields reject (return undefined); optional fields drop-if-invalid. ## Decisions

### I1 — Gate image-promotion on `!isBudgetExceeded && !decision.isBudgetForced`

**Explored**:

- (a) Add both gates at the outer `if (imageAttached)` block — minimal-diff, semantically clean.
- (b) Strip `isBudgetForced` from carry-forward at `provider.ts:419` so the promoted decision doesn't claim budget — leaves the budget force undetected, worse UX.

**Decision**: (a). The outer block is the right gate because once image-promotion runs, the budget is already defeated; no point mutating provenance after the fact.

**Evidence**: `provider.ts:300` captures `isBudgetExceeded` const snapshot; `provider.ts:386` enters the image-promotion block. Same line as `pinnedTier` (`provider.ts:298`).

### I2 — `tiersToTry = pinnedTier ? [] : ...`

**Explored**:

- (a) Skip promotion entirely when `pinnedTier` is set; image filter at `provider.ts:494-510` surfaces a skip reason.
- (b) Modify the Google continuation guard to remove the `!pinnedTier` skip — incorrect: the guard exists to handle the case where the user pinned a _specific_ model, which is a stronger constraint than a tier pin.
- (c) Document that pin only pins the tier — same as (b), worse UX because `isPinned` carries the lie.

**Decision**: (a). Pin is a tier-promise, not a model-promise; image promotion would violate that promise.

**Evidence**: `provider.ts:298` `const pinnedTier = state.pinnedTierByProfile[model.id];`; `provider.ts:344` Google guard already treats `pinnedTier` as a hard pin.

### I3 — Drop `level: ThinkingLevel` parameter from `getUnsupportedTiers`

**Explored**:

- (a) Restore the `'off'` short-circuit at `config.ts:692` — leaves `level` as a dead parameter.
- (b) Remove `'off'` filters at `index.ts:518` and `commands.ts:370` — surfaces nonsensical warnings ("may not support 'off'") and contradicts precedent lesson #3 (`'off'` semantics never survive first contact).
- (c) Drop the `level` parameter from `getUnsupportedTiers`; callers keep their guards — honest contract, smallest API surface.

**Decision**: (c). The function answers "which tiers lack reasoning capability"; level-appropriateness is the caller's responsibility. Advisors confirms this matches the review's own Alt.

**Evidence**: `config.ts:687-704` body never reads `level`; `config.ts:692` removed the only consumer.

### Q1 — Add `isVetoed` to notify chain; document chain/flags divergence

**Explored**:

- (a) Add `isVetoed` to chain at `index.ts:104` — single-winner notify source, exhaustive widget flags.
- (b) Unify on `getDecisionFlags` for the notify — clutters the notify line with comma-separated flags.
- (c) Unify on chain for both — drops `isVetoed` from widget, regresses `ui.test.ts:107-137`.

**Decision**: (a). The chain is for human-readable single-label notification; the flag list is for exhaustive widget provenance. Both are correct; the divergence is intentional.

**Evidence**: `index.ts:99-107` priority chain; `ui.ts:19-26` accumulator; both consume `lastDecision` independently.

### Q2 — Per-field validator (`sanitizeRoutingDecisionFields`) + per-field drop at consumer

**Explored**:

- (a) Expand `isValidRoutingDecision` to validate all optional fields; reject whole on any bad — keeps current all-or-nothing, doesn't fix the discard problem.
- (b) Split into `sanitizeRoutingDecisionFields(value): RoutingDecision | undefined` that strips bad optional fields and returns undefined only on bad required fields. Consumer does the drop. — matches the `accumulatedCost` pattern at `state.ts:48-56` extended to nested objects.

**Decision**: (b). Required fields (profile, tier, timestamp) are not negotiable; optional fields (flags, phase, targetProvider, targetModelId, targetLabel, thinking, classifier provenance) can be dropped without invalidating the state.

**Evidence**: `state.ts:48-56` `accumulatedCost` validate-if-present; `state.ts:9-15` `isValidPinByProfile` per-key walk.

**Sub-decision**: Add `isRouterPhase` type guard in `config.ts:42-46` style (equality chain: `value === 'planning' || value === 'implementation' || value === 'lightweight'`). Sanitizer must default **all 6** non-optional fields of `RoutingDecision` (not just `phase` + `thinking`) since the interface declares them required at `types.ts:70-79` — string fields default to `''`, enums default to the values above.

### Q3 — Add `tier === 'low' && isBudgetExceeded` floor branch

**Explored**:

- (a) Third `else if` branch at `routing.ts:445` setting `isBudgetForced = true` with floor warning.
- (b) Document that `'low'` is the floor and no warning is needed — silent for users with exceeded budget on low-tier decisions.

**Decision**: (a). The flag semantic stays honest: budget-exceeded means we tried to honor the cap; `'low'` with no further option still deserves notification.

**Evidence**: `routing.ts:434-444` existing else-if chain; `buildDelegationTierChain('low', true) === ['low']` per `routing.test.ts:1053`.

### extensions/state.ts:29-50 — MODIFY (Slice 1)

Replace the boolean `isValidRoutingDecision` with a per-field sanitizer. The sanitizer returns a `RoutingDecision` with invalid optional fields stripped (and a defensive default for `phase` and `thinking` since they're effectively required at runtime), or `undefined` if the three required fields (`profile`, `tier`, `timestamp`) are bad or the value isn't an object.

`isRouterPersistedState` keeps its boolean shape: it now only checks the _required_ fields of `lastDecision` (matching the previous behavior for corrupt required fields) and lets the consumer (`index.ts:336`) run the sanitizer to do the per-field drop.

**Full file replacement for `extensions/state.ts`** (Slice 1 produces this exact file):

```typescript
import type {
  RouterPinByProfile,
  RouterThinkingByProfile,
  RoutingDecision,
  RouterPersistedState,
} from './types';
import {
  isRouterTier,
  isThinkingLevel,
  isObjectRecord,
  isRouterPhase,
} from './config';

const isValidPinByProfile = (value: unknown): boolean => {
  if (!isObjectRecord(value)) return false;
  for (const tier of Object.values(value)) {
    if (tier !== undefined && !isRouterTier(tier)) return false;
  }
  return true;
};

const isValidThinkingByProfile = (value: unknown): boolean => {
  if (!isObjectRecord(value)) return false;
  for (const tierMap of Object.values(value)) {
    if (tierMap === undefined) continue;
    if (!isObjectRecord(tierMap)) return false;
    for (const level of Object.values(tierMap)) {
      if (level !== undefined && !isThinkingLevel(level)) return false;
    }
  }
  return true;
};

const isOptionalBoolean = (v: unknown): v is boolean => typeof v === 'boolean';

const isOptionalString = (v: unknown): v is string => typeof v === 'string';

const isConfidenceLevel = (
  v: unknown,
): v is NonNullable<RoutingDecision['confidence']> =>
  v === 'high' || v === 'medium' || v === 'low';

const isVetoReason = (
  v: unknown,
): v is NonNullable<RoutingDecision['vetoReason']> => v === 'explicit-hint';

const isFailureReason = (
  v: unknown,
): v is NonNullable<RoutingDecision['failureReason']> =>
  v === 'success' || v === 'unparseable';

/**
 * Per-field sanitizer for a persisted `RoutingDecision`.
 *
 * Required fields (`profile`, `tier`, `timestamp`) reject-whole — returns
 * `undefined` if any are bad. The 6 non-optional RoutingDecision fields
 * declared in `types.ts:70-79` (`phase`, `targetProvider`, `targetModelId`,
 * `targetLabel`, `reasoning`, `thinking`) are defaulted when invalid so the
 * returned value always satisfies the interface (string → `''`, phase →
 * `'implementation'`, thinking → `'medium'`). The 11 optional fields (7
 * boolean flags + 4 classifier provenance) are dropped if invalid.
 */
export const sanitizeRoutingDecisionFields = (
  value: unknown,
): RoutingDecision | undefined => {
  if (!isObjectRecord(value)) return undefined;
  if (typeof value.profile !== 'string') return undefined;
  if (typeof value.tier !== 'string' || !isRouterTier(value.tier)) {
    return undefined;
  }
  if (typeof value.timestamp !== 'number') return undefined;

  const out: RoutingDecision = {
    profile: value.profile,
    tier: value.tier,
    timestamp: value.timestamp,
  };
  // Defaults for ALL non-optional RoutingDecision fields. The interface
  // (types.ts:70-79) requires 6 fields beyond profile/tier/timestamp; we
  // provide defensive defaults for corrupted persisted state so downstream
  // consumers (statusline at index.ts, delegate-reasoning at provider.ts)
  // always see well-typed values.
  out.phase = isRouterPhase(value.phase) ? value.phase : 'implementation';
  out.targetProvider = isOptionalString(value.targetProvider)
    ? value.targetProvider
    : '';
  out.targetModelId = isOptionalString(value.targetModelId)
    ? value.targetModelId
    : '';
  out.targetLabel = isOptionalString(value.targetLabel)
    ? value.targetLabel
    : '';
  out.reasoning = isOptionalString(value.reasoning) ? value.reasoning : '';
  out.thinking = isThinkingLevel(value.thinking) ? value.thinking : 'medium';
  if (isOptionalBoolean(value.isClassifier)) {
    out.isClassifier = value.isClassifier;
  }
  if (isOptionalBoolean(value.isFallback)) {
    out.isFallback = value.isFallback;
  }
  if (isOptionalBoolean(value.isBudgetForced)) {
    out.isBudgetForced = value.isBudgetForced;
  }
  if (isOptionalBoolean(value.isRuleMatched)) {
    out.isRuleMatched = value.isRuleMatched;
  }
  if (isOptionalBoolean(value.isPinned)) {
    out.isPinned = value.isPinned;
  }
  if (isOptionalBoolean(value.isVetoed)) {
    out.isVetoed = value.isVetoed;
  }
  if (isVetoReason(value.vetoReason)) {
    out.vetoReason = value.vetoReason;
  }
  if (isConfidenceLevel(value.confidence)) {
    out.confidence = value.confidence;
  }
  if (isOptionalString(value.rawText)) {
    out.rawText = value.rawText;
  }
  if (isFailureReason(value.failureReason)) {
    out.failureReason = value.failureReason;
  }
  return out;
};

/**
 * Required-field check used inside `isRouterPersistedState`.
 * Returns true iff the value is an object AND its three required fields
 * are present and well-typed. Optional fields are not checked here — the
 * consumer runs `sanitizeRoutingDecisionFields` to strip bad optional
 * fields without rejecting the whole state.
 */
const hasValidRequiredDecisionFields = (value: unknown): boolean => {
  if (!isObjectRecord(value)) return false;
  if (typeof value.profile !== 'string') return false;
  if (typeof value.tier !== 'string' || !isRouterTier(value.tier)) return false;
  if (typeof value.timestamp !== 'number') return false;
  return true;
};

export const isRouterPersistedState = (
  value: unknown,
): value is RouterPersistedState => {
  if (!isObjectRecord(value)) return false;
  const v = value;
  // Required core (existing)
  if (typeof v.enabled !== 'boolean') return false;
  if (typeof v.selectedProfile !== 'string') return false;
  if (typeof v.timestamp !== 'number') return false;
  // Optional fields: validate-if-present (mirrors config.ts:285-289 pattern)
  if (v.accumulatedCost !== undefined) {
    if (
      typeof v.accumulatedCost !== 'number' ||
      Number.isNaN(v.accumulatedCost) ||
      !Number.isFinite(v.accumulatedCost)
    ) {
      return false;
    }
  }
  if (v.pinByProfile !== undefined && !isValidPinByProfile(v.pinByProfile))
    return false;
  if (
    v.thinkingByProfile !== undefined &&
    !isValidThinkingByProfile(v.thinkingByProfile)
  )
    return false;
  if (v.pinTier !== undefined && !isRouterTier(v.pinTier)) return false;
  // Q2: lastDecision only blocks the whole state when its REQUIRED fields
  // are bad. Optional fields are sanitized separately at the consumer
  // (extensions/index.ts restore path) so a corrupt optional field no
  // longer discards the rest of the persisted state.
  if (
    v.lastDecision !== undefined &&
    !hasValidRequiredDecisionFields(v.lastDecision)
  ) {
    return false;
  }
  if (v.debugEnabled !== undefined && typeof v.debugEnabled !== 'boolean')
    return false;
  if (v.widgetEnabled !== undefined && typeof v.widgetEnabled !== 'boolean')
    return false;
  if (
    v.lastNonRouterModel !== undefined &&
    typeof v.lastNonRouterModel !== 'string'
  )
    return false;
  return true;
};

export const buildPersistedState = (
  routerEnabled: boolean,
  selectedProfile: string | undefined,
  pinnedTierByProfile: RouterPinByProfile,
  thinkingByProfile: RouterThinkingByProfile,
  debugEnabled: boolean,
  widgetEnabled: boolean,
  debugHistory: RoutingDecision[],
  lastDecision: RoutingDecision | undefined,
  lastNonRouterModel: string | undefined,
  accumulatedCost: number,
): RouterPersistedState => {
  return {
    enabled: routerEnabled,
    selectedProfile: selectedProfile ?? '',
    pinTier: selectedProfile ? pinnedTierByProfile[selectedProfile] : undefined,
    pinByProfile: { ...pinnedTierByProfile },
    thinkingByProfile: { ...thinkingByProfile },
    debugEnabled,
    widgetEnabled,
    debugHistory,
    lastDecision,
    lastNonRouterModel,
    accumulatedCost,
    timestamp: Date.now(),
  };
};
```
